## Design & Graphisme

- **Typographie héroïne** : Les sérifs élégants s'imposent en titrage, la typo devient interface (navigation rotative, labels dynamiques liés au scroll).
- **Dopamine Design vs Calm UI** : Coexistence des deux extrêmes — palettes saturées Y2K pour les brands jeunes, interfaces épurées "anti-surcharge" pour le SaaS.
- **Soft UI hybride** : Retour du neomorphisme, version 2026 : surfaces douces + ombres contrastées + meilleure accessibilité intégrée dès la conception.
- **Accessibilité = infrastructure** : Ce n'est plus une option, les outils de design (Figma, etc.) l'imposent dès le wireframe.
