# Veille du 2026-11-26

## Design & Graphisme

- **Typographie expressive** : oversized type avec contrastes de poids, variable fonts réactives au scroll/curseur, titres serif + chiffres style ledger pour un rendu éditorial. La typo devient système visuel principal.
- **IA générative dans l'UI** : interfaces construites depuis des prompts texte (generative UI), l'IA s'intègre comme copilote dans le workflow designer. Les outils Figma/Adobe AI sont désormais standard.
- **Glassmorphism spatial** : "liquid glass" persiste dans les interfaces immersives et spatiales (visionPro, XR).
- **Neuro-inclusive design** : contrôle utilisateur des animations, autoplay désactivable par défaut — accessibilité = différenciateur concurrentiel.
