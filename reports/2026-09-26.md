# Veille du 2026-09-26

## Design & Graphisme

- **Typographie héroïque** : La typo devient l'image principale — texte superposé, masqué sur photo, gradients. Les serifs maximaux (ex. Denton) dominent avec contrastes dramatiques.
- **Variable Fonts** : Un seul fichier, plusieurs graisses/largeurs — incontournable pour le responsive design en 2026.
- **Interfaces calmes** : Fin du spectacle visuel. L'UI 2026 mise sur la clarté cognitive : espacement généreux, hiérarchie nette, zéro friction.
- **Digital Neon vs Quiet Luxury** : Coexistence des deux extrêmes — néons digitaux pour le gaming/crypto, neutrals premium pour le branding haut de gamme.

- **Pantone 2026** : Cloud Dancer `#F4F3EF` — blanc aérien, calme, omniscient sur les interfaces SaaS.
