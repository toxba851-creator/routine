# Veille du 2026-09-28

## Design & Graphisme

- **Interfaces calmes** : la tendance 2026 abandonne le visual theatrics — interfaces épurées, espacement généreux, contrastes doux. Moins de décoration, plus de fluidité cognitive.
- **Sérifs expressifs de retour** : les sérifs maximaux (ex. Denton) avec forts contrastes de graisse s'imposent comme élément héros — la typo remplace l'image.
- **Variable fonts** : dominent le web responsive en 2026, un seul fichier pour tous les graisses/largeurs — gain de performance + flexibilité.
- **IA transparente** : les interfaces affichent explicitement quand du contenu est généré par IA. Confiance utilisateur = nouveau critère UX.
