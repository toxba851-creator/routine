# Veille du 2026-08-23

## Design & Graphisme

- **Typographie cinétique** : les textes animés/morphants dominent les hero sections en 2026 — outils : CSS View Transitions + Animation API. Tendance forte pour portfolios et pages créatives.
- **Sérifs bold + minimalisme** : titres en serifs élégants grands formats, layouts épurés avec beaucoup de whitespace. Le minimalisme l'emporte sur le maximalisme pour les interfaces SaaS.
- **3D/Spatial design** : intégrations 3D légères dans les landing pages, surtout pour les produits tech/IA.
- **Accessibilité = infrastructure** : en 2026, concevoir pour la diversité visuelle/motrice n'est plus optionnel — c'est le standard de base.
